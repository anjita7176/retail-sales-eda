# 📊 Retail Sales Exploratory Data Analysis (EDA)

### Python | Pandas | NumPy | Matplotlib | Seaborn

An end-to-end Exploratory Data Analysis project focused on understanding retail sales data, identifying business patterns, and extracting meaningful insights through data analysis and visualization.

## 🎯 Project Objectives

- Explore and understand the retail dataset.
- Identify missing values and duplicate records.
- Clean and prepare data for analysis.
- Analyze sales and profit distributions.
- Compare performance across product categories and regions.
- Explore monthly sales trends.
- Summarize key business performance indicators.

## 🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Project Files

| File | Description |
|---|---|
| `Retail_Sales_EDA.ipynb` | Notebook containing data cleaning, exploratory analysis, and visualizations |
| `retail_sales_cleaned.csv` | Cleaned dataset exported for further analysis |

*Note: The notebook filename should match the actual filename uploaded to this repository.*

## 🔍 Analysis Workflow

1. Data loading and inspection
2. Data quality assessment
3. Data cleaning and preprocessing
4. Descriptive statistical analysis
5. Sales and profit distribution analysis
6. Category and regional performance analysis
7. Monthly sales trend visualization
8. Key Performance Indicator (KPI) summary
9. Exporting the cleaned dataset

## 📈 Key Learning Outcomes

- Practiced real-world data cleaning techniques.
- Improved skills in Pandas-based data manipulation.
- Created visualizations to explore business trends.
- Learned to summarize retail performance using KPIs.
- Developed a reproducible EDA workflow.

## 🚀 How to Run

1. Open the Jupyter Notebook in this repository.
2. Upload the required CSV dataset in Google Colab.
3. Run the notebook cells in sequence.
4. Review the analysis outputs and visualizations.
